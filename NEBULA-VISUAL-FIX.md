# Туманности на карте галактики снова видимы (и по реальным данным)

## Жалоба

После переработки слоя туманностей на карте галактики от них остались только
подписи и кликабельность — самого «газа» не было видно ни на одном масштабе.

## Причина

Вершинный шейдер `NebulaField.tsx` писал в собственный атрибут:

```glsl
iSize *= boost;   // атрибуты в GLSL только для чтения
```

three r185 конвертирует GLSL1-шейдер `ShaderMaterial` в `#version 300 es`
(`#define attribute in`), а запись во `in`-переменную — ошибка компиляции
(`l-value required … can't modify shader input`). Драйвер отбрасывает
программу, оба инстанс-меша (светящиеся и тёмные облака) не рисуют ничего,
а HTML-подписи продолжают работать — ровно та картина, что описана в жалобе.
CPU-превью (`scripts/preview-nebulae.mjs`) ошибку поймать не могло: оно
считает ту же раскладку, но без GLSL.

## Что сделано

1. **Шейдер**: раздутый экранный размер живёт в локальной переменной
   `puffSize`, атрибуты не трогаются.
2. **Регресс-защита**: `scripts/check-nebula-shaders.mjs` извлекает оба
   шейдера из `NebulaField.tsx`, оборачивает префиксом three (как
   `WebGLProgram.js`) и прогоняет через настоящий компилятор ESSL
   (glslang, пакет `glslang-wasm-validator`, devDependency). Подключено
   тестом в `scripts/tests/galaxy-nebulae.test.mjs` — «подписи есть, газа
   нет» больше не пройдёт молча.
3. **Видимость на всех масштабах**: экранные константы вынесены в
   `nebulaClouds.ts` (`SCREEN_MIN_PIXELS = 10`, `SCREEN_FADE_CURVE = 1.2`,
   `SCREEN_FADE_FLOOR = 0.16`) и общие для шейдера и превью. Раньше пол
   затухания был 0.03 — на масштабе всей Галактики дымка гасла в ноль,
   теперь каждая туманность остаётся мягкой цветной дымкой; клубы крупнее и
   мягче (фолл-оф атласа 2.1 → 1.4, доли размера 0.28–0.8, купол 0.34),
   поэтому газ читается сплошным, а не россыпью точек.
4. **Реальные астрономические данные**: в каталог (`build-nebula-catalog.mjs`)
   добавлено `ratio` — отношение осей b/a из OpenNGC (MinAx/MajAx) для
   ~30 объектов, у которых оно измерено. Раскладка клубов сплющивает облако
   в эллипс с этим отношением: Калифорния 0.25, Орёл 0.21, Розетка 0.62 и
   т.д. Позиции и так брались из RA/Dec OpenNGC + игровых дистанций, размер —
   из углового MajAx.

## Проверка

- `node scripts/check-nebula-shaders.mjs` → «компиляция OK»; сломанный
  вариант (запись в атрибут) валидатор отклоняет.
- `node --test scripts/tests/galaxy-nebulae.test.mjs` → 17/17 (включая новые
  тесты: дальний план не гасит дымку; вытянутость следует b/a из OpenNGC).
- `npm test` → 1181/1181. `npm run typecheck` и `npm run build` → без ошибок.
- `node scripts/preview-nebulae.mjs --sheet` — превью тех же формул, что в
  шейдере: на масштабе Галактики туманности — цветные дымки, вблизи —
  сплошной газ (дуга Петли Барнарда, нити Вуали, эллипс Калифорнии).

Ограничение: в песочнице нет браузера/WebGL, поэтому живой рендер не
снимался; шейдеры проверены тем же фронтендом Khronos, которым драйвер
валидирует ESSL, а композитинг — собственным превью проекта.
