# Local 3D map font

DejaVu Sans 2.37 (`DejaVuSans.ttf`), distributed under the Bitstream Vera license
with DejaVu additions in the public domain. The full license is adjacent.
Source: https://dejavu-fonts.github.io/ (Debian fonts-dejavu-core distribution).

Covers Latin, Cyrillic, Greek and many symbols without Troika's external font
resolver. Exotic glyphs not in this font may still use Troika's fallback CDN.
The font is served from this site so ordinary map labels also work without a CDN.
