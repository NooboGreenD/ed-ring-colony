# Инженеры: карточка больше не уезжает под шапку

Дата: 2026-10-01. Разбор жалобы: «выбираешь одного инженера и прокручиваешь
вниз — информация об инженере заезжает под шапку сайта».

## Причина

Правая панель с деталями (`.eng-details` в
`src/components/Engineers/EngineerTree.tsx`) прилипала к верху окна
(`position: sticky; top: 12px`), а шапка сайта — `position: sticky; top: 0`
с `z-index: 50` (см. `globals.css`, ~строка 123). При прокрутке верх карточки
оказывался **под** шапкой: заголовок с именем инженера и кнопка «×»
становились невидимыми и некликабельными, панель продолжала скроллиться
«за» шапкой.

## Исправление

```css
.eng-details { position: sticky; top: 64px; max-height: calc(100vh - 76px);
               overflow-y: auto; z-index: 1; }
```

* `top: 64px` — панель останавливается **ниже** шапки, а не под ней;
* `max-height: calc(100vh - 76px)` + `overflow-y: auto` — у панели появляется
  собственная прокрутка, поэтому длинные карточки (G5-чертежи, несколько
  наборов навыков) больше не «убегают» за край экрана;
* `z-index: 1` — панель выше контента, но не пытается перекрыть шапку.

Мобильная раскладка (`@media (max-width: 900px)`, панель в один столбец под
деревом) не менялась — там панель не прилипает.

## Проверка

Страница «Инженеры» → выбрать инженера с длинным списком чертежей →
прокрутить список вниз: карточка видна целиком, имя и кнопка закрытия
доступны, длинное содержимое прокручивается внутри панели.
