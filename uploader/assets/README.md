# Colonial Helper — иконки приложения

## Дизайн

`colonial-helper-master.png` — выбранный пользователем AI-generated исходник
2048×2048 RGBA: янтарное орбитальное кольцо, корабль, один бирюзовый огонь.
Палитра продолжает стиль ED Ring Colony. Внешний фон прозрачный; тёмная
область внутри эмблемы — часть рисунка. Мастер не попадает в пакет обновления.

В трее мелкие панели исходника потерялись бы. Для него выполнена оптическая
перерисовка того же мотива: широкие дуги кольца, контрастный силуэт корабля,
бирюзовый огонь, без надписей и микродеталей. Графитовая обводка помогает
на светлой панели задач, яркие заливки — на тёмной.

## Файлы поставки (в корне `uploader/`)

- `colonial_helper.ico`: 16, 20, 24, 32, 40, 48, 64, 128, 256 px, 32-bit RGBA.
  На 16–32 px используется оптически упрощённый рисунок, на больших размерах
  — выбранный подробный дизайн. Используется окном, Alt+Tab, EXE и Setup.
- `colonial_helper.png`: 512×512, подробный рисунок; резервный формат Qt.
- `colonial_helper_tray.ico`: 16, 20, 24, 32, 40, 48, 64 px, упрощённый знак.
- `colonial_helper_tray.png`: 64×64, резервный формат для трея.

В пользовательской рамке окна используется упрощённый знак 20 px.
Четыре ресурса перечислены явно в `app_icons.ICON_ASSETS`; `build_bundle`
добавляет их в подписываемый манифест, ZIP обновления и встроенный пакет.
Пути ищутся относительно модуля/пакета и каталога PyInstaller `_MEIPASS`,
не относительно текущей рабочей папки ярлыка.

## Воспроизводимая подготовка

Только на машине разработчика (Pillow не нужен в программе):

```sh
python -m pip install Pillow
python scripts/build-helper-icons.py
```

Скрипт изменяет только четыре ресурса поставки. Перерисовка для трея задана
геометрией в скрипте; повторная генерация изображения через AI не требуется.

## Выпуск

Иконки окна/трея доставляются обычным обновлением пакета кода. Для смены
иконки **самого файла EXE**, Setup и новых ярлыков необходимо пересобрать
Windows-лаунчер и установщик (`build_exe.py`, затем `build_installer.py`).
Оба сборщика задают PE-иконку через `--icon` и кладут ресурсы Qt через
`--add-data`. Старый уже установленный EXE не меняет встроенную иконку от
одного обновления Python-кода. Проводник Windows также может кэшировать
иконку ранее созданного ярлыка.

Нативная сборка Windows и внешний вид в реальном системном трее требуют
отдельной проверки на Windows; одни headless-тесты этого не подтверждают.
